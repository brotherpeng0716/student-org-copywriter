# 可选环境说明

## 普通文本写作：不需要安装任何内容

如果你只需要在对话框获得 Markdown、邮件正文、公众号正文或群通知，直接让模型完整读取 `SKILL.md` 即可。无需 Python、Node.js、插件、账号或 API Key。

## 文件导出：取决于模型的实际工具能力

创建 Word DOCX、PDF、HTML 或 Markdown 文件，需要你所用的模型或平台确实能创建并保存文件。没有这种能力时，模型应交付可复制的文本，并在 `状态检查` 中说明“文件生成未完成”，不能假装已经生成下载文件。

## 联网、浏览器与识图：同样取决于实际能力

- 验证报名链接需要联网和浏览器操控能力；仅能看到 URL 不等于已经验证。
- 读取海报、二维码、截图或扫描件需要图像理解能力。
- 检查 DOCX/PDF 的视觉排版需要能渲染文件并查看页面图片。

Skill 要求模型如实把能力外的事项写入 `状态检查`。不要为了使用本 Skill 安装不明插件、泄露账号密码或提交表单。

## 可选的本地 DOCX/PDF 依赖

如果你正在自行编写本地自动化脚本来生成 DOCX 或 PDF，可参考 `optional-docx-requirements.txt`。这些依赖**不是**使用本 Skill 的必要条件，也不会让普通聊天模型自动获得文件、联网或浏览器能力。
