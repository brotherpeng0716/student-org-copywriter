# TIDE Club 文案 Skill｜零基础使用教程

这是一套给 **TIDE Club** 使用的校园文案工作规则。它会默认采用 TIDE Club（Technology and Innovation in Digital Era，数据潮）的组织语境，帮助你完成活动邮件、项目招募、Workshop 邀请、公众号推文、群通知、讲座、回顾和中英文内容。

你不需要会编程，也不需要安装 Python、Node.js 或申请 API Key。只要把完整的 `SKILL.md` 交给模型阅读，再告诉它你的活动资料即可。

> 适合 TIDE Club 的默认风格：科技社团的专业感 + 学生组织的亲和力 + 项目实践的行动导向。它不会凭空补写嘉宾、合作方、名额、链接或承诺。

## 1. 这个压缩包 / 仓库里有什么

| 文件或文件夹 | 给谁用 | 用途 |
| --- | --- | --- |
| `SKILL.md` | 模型 | 核心规则。每次使用时要让模型**完整阅读**它。 |
| `README.md` | 你 | 本教程。 |
| `agents/openai.yaml` | Codex | Codex 中显示名称和默认调用提示。普通聊天模型不需要它。 |
| `environment/` | 需要导出文件的人 | 说明何时需要额外环境；普通文本写作无需安装。 |
| `PACKAGE_MANIFEST.md` | 你 | 压缩包内容清单。 |
| `docs/`、`src/`、`progress/`、`showcase/` | 项目维护者 | 分别存放设计资料、实现、周报与展示材料；首次使用可以先不管。 |

**最重要的是 `SKILL.md`。** 不要只复制其中一小段，也不要让模型“自行概括规则后再执行”；请让它完整读取并遵守。

## 2. 先选一种最适合你的用法

| 你使用的模型 | 最简单的方法 |
| --- | --- |
| Codex | 把整个文件夹放进 Codex 的 `skills` 文件夹，再用 `$student-org-copywriter` 调用。 |
| DeepSeek、元宝 | 能上传知识文件或创建智能体时上传 `SKILL.md`；否则在一个新对话的第一条消息完整粘贴 `SKILL.md`。 |
| ChatGPT、Kimi、Claude 或其他聊天模型 | 新建对话，上传 `SKILL.md`（如模型支持）或完整粘贴其内容，然后发送固定加载语。 |

不同产品的按钮名称会随版本改变，例如“上传文件”“知识库”“智能体”“自定义指令”。找不到这些功能也没关系：使用“完整粘贴 `SKILL.md` 到新对话”的方法即可。

## 3. 通用方法：任何聊天模型都能照做

这是最稳妥的方法，适用于 DeepSeek、元宝和其他普通聊天模型。

### 第一步：新建一个对话

建议一个活动或一组关联文案使用一个单独对话，避免旧活动的信息混入新活动。

### 第二步：加载 Skill

打开 `SKILL.md`，全选、复制，然后把下面这段话和 `SKILL.md` 全部内容一起发送给模型：

```text
下面是 TIDE Club 文案 Skill 的固定工作规则。请完整阅读并在本次对话中严格遵守。
不要删改、缩写或忽略规则；收到后只回复：Skill 已加载，请提供活动资料和交付格式。

[在这里粘贴 SKILL.md 的全部内容]
```

若模型支持上传文件，也可以上传 `SKILL.md`，再发送上面的前两行。模型回复“Skill 已加载”后，再进行下一步。

### 第三步：发送活动资料和想要的交付格式

Skill 会要求先确定格式。你可以直接写清楚，减少来回沟通：

```text
请使用已加载的 TIDE Club 文案 Skill。

交付格式：对话 Markdown
发布渠道：活动邀请邮件
语言：中文

活动名称：……
主办方：TIDE Club
活动时间：……
活动地点：……
面向对象：……
报名方式 / 链接：……
报名截止时间：……
活动亮点：……
嘉宾及介绍：……
参与要求、名额、联系人或其他说明：……
```

可选的交付格式包括：`对话 Markdown`、`Word DOCX`、`HTML 邮件`、`PDF`、`Markdown 文件`、`TXT`。如果只是想先看文案，请选 **对话 Markdown**。

### 第四步：看模型给出的四个内部区块

模型交付正文后，应在正文之外附上这些区块：

- `状态检查`：它在这次对话中实际具备什么能力，哪些动作没有能力做。
- `发布状态`：草稿、待确认后发布或可发布。
- `待确认`：缺失、冲突或未验证的信息，逐项列出。
- `本次变更`：只有在你要求修改旧文案或一次生成多渠道内容时才需要。

发布前重点看 `待确认`。只要日期、报名链接、嘉宾信息、授权或材料还有必要缺口，就不要把它当成已经确认可发布的版本。

## 4. Codex 使用方法（Windows）

### 安装

1. 解压本压缩包。
2. 打开文件夹 `student-org-copywriter`。
3. 将整个文件夹复制到下面的位置，并保持文件夹名为 `student-org-copywriter`：

```text
C:\Users\你的 Windows 用户名\.codex\skills\student-org-copywriter\
```

例如，Windows 用户名为 `Alice` 时，路径是：

```text
C:\Users\Alice\.codex\skills\student-org-copywriter\
```

4. 确认该文件夹中直接包含 `SKILL.md` 和 `agents` 文件夹，而不是多套了一层同名文件夹。
5. 重启 Codex，或新建一个 Codex 对话。

### 调用

在 Codex 对话中输入：

```text
使用 $student-org-copywriter，交付格式为对话 Markdown。
请为 TIDE Club 写一封活动邀请邮件：
活动名称：……
时间：……
地点：……
报名方式：……
```

如果没有识别到 `$student-org-copywriter`，请检查：

- 文件夹名是否恰好为 `student-org-copywriter`；
- `SKILL.md` 是否位于该文件夹第一层；
- 是否重启或新建了 Codex 对话；
- 文件是否被错误保存成 `SKILL.md.txt`。

## 5. DeepSeek 与元宝使用方法

两者的产品界面可能更新，但按下面顺序操作即可。

### 有“上传文件 / 知识库 / 智能体”功能时

1. 新建一个与 TIDE 文案相关的对话或智能体。
2. 上传 `SKILL.md`。
3. 在首条消息发送：

```text
请完整阅读已上传的 SKILL.md，并在本次对话中严格按其中规则执行。
收到后只回复：Skill 已加载，请提供活动资料和交付格式。
```

4. 收到确认后，按照第 3 节的“活动资料模板”提交任务。

### 没有上传功能时

使用第 3 节的“通用方法”：在新对话的第一条消息中完整粘贴 `SKILL.md`，再发送活动资料。

我们已在 DeepSeek、元宝等模型上进行过定性使用测试，常规文本生成表现良好；不同模型对文件导出、网页验证和图片读取的支持并不相同，仍应以每次输出中的 `状态检查` 为准。

## 7. 文件、联网、浏览器与识图：哪些情况下做不了

文本写作不需要安装环境，但模型是否能完成下列动作，取决于它**实际提供的工具**：

| 你希望它做什么 | 需要的能力 | 没有能力时正确结果 |
| --- | --- | --- |
| 生成可下载的 DOCX / PDF | 文件创建与保存 | 给出 Markdown / 文本，并在 `状态检查` 说明未生成文件。 |
| 确认报名链接可打开 | 联网 + 浏览器操控 | 标为“未验证”，不能声称链接可用。 |
| 读取海报、二维码、截图 | 图像理解 | 请你提供图片中的文字，不能猜测图片内容。 |
| 检查 DOCX / PDF 排版 | 视觉渲染与图像检查 | 标为“未完成视觉检查”，不能声称排版已检查。 |

不要要求模型在没有工具时假装已经打开网页、识别二维码、提交报名表或创建文件。Skill 的设计目标是如实标注能力边界，而不是编造已完成的操作。

更多说明见 [environment/README.md](environment/README.md)。

## 8. 常见问题

### Q1：我只想快速写一段群通知，也要加载整份 Skill 吗？

建议加载。它会帮助你检查时间、链接和待确认信息；加载后只需说明“群通知、对话 Markdown、简短直接”。

### Q2：模型没有主动问我选什么格式怎么办？

直接在任务第一行写：`交付格式：对话 Markdown`。想要文件时再明确写 `Word DOCX` 或 `PDF`。

### Q3：我给的信息不完整，它还能写吗？

可以先写草稿，但不应编造事实。模型应把缺少的具体信息放在 `待确认` 中；补齐后再让它修改同一版文案。

### Q4：我能把 Skill 发给其他同学吗？

可以。将整个 `student-org-copywriter` 文件夹或本压缩包发送给对方。对方只需按本 README 的模型对应方法加载 `SKILL.md`。

### Q5：模型写出来不像 TIDE Club 怎么办？

确认你让模型完整读取了 `SKILL.md`，并在任务中写明“使用 TIDE Club 默认特化内容”。同时提供真实的项目或活动事实；Skill 不会用虚构信息替代缺失资料。

## 10. 版本与使用边界

本仓库中的 `SKILL.md` 是当前最新版。上传到第三方模型时，请以同一包内的 `SKILL.md` 为准，避免用到旧版规则。

Skill 可以帮助组织、核对并生成文案；它不会替代活动负责人对事实、公开授权、校内规范和最终发布内容的确认。
